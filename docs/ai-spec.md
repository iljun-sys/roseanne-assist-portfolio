## 2. 기능별 상세 명세

### AI-1 / AI-2. AI 브리핑 · SOAP 요약
`supabase/functions/generate-briefing/index.ts`

| 항목 | 값 |
| --- | --- |
| 트리거 | **수동** — 원장이 버튼 클릭 (자동 생성 금지, 비용·오남용 방지) |
| 입력 | 문진 데이터 전체(JSON 직렬화) + `mode`(`briefing`\|`soap`) + `model`(`haiku`\|`sonnet`) |
| 모델 | `claude-haiku-4-5-20251001` (기본) / `claude-sonnet-4-20250514` (**⚠️ 은퇴 — §4 참조**) |
| max_tokens | 800 |
| temperature | **미지정**(기본값) — 원칙 C 위반 |
| 저장 | `visit_ai_results.briefing` / `.soap_summary` / `.model_used` |
| 모델 표시 | 화면에 "⚡ Haiku로 생성됨" / "🧠 Sonnet으로 생성됨" 배지 노출 |

**브리핑 출력 스키마**
```json
{
  "alerts": ["즉시 확인 필요 (알레르기·약물 상호작용 등)"],
  "chief_complaint_summary": "주요 증상 요약 (1-2문장)",
  "history_highlights": ["관련 병력 요점"],
  "differential_hints": ["감별 진단 힌트"],
  "recommended_questions": ["추가 문진 제안"],
  "ai_summary": "종합 브리핑 (3-5문장)"
}
```
> ✅ **원칙 G(칸 분리)를 부분 충족**: `history_highlights`(과거력)와 `differential_hints`(감별진단)가 분리돼 있어, 모델이 진단 칸을 채우려고 과거력을 끌어다 쓰는 오분류를 구조적으로 막는다.

**SOAP 출력 스키마**
```json
{ "s": "환자 주관적 호소", "o": "객관적 소견", "a": "평가/인상(감별진단)", "p": "계획" }
```

**제약(Constraints)** — 프롬프트에 명시된 것: 한국어 / 간결·임상적으로 유용한 정보만 / null·빈 값 필드 무시 / alerts 없으면 빈 배열

### AI-3. 음성 진료 요약
`supabase/functions/transcribe-and-summarize/index.ts`

| 항목 | 값 |
| --- | --- |
| 트리거 | 원장이 녹음 종료 |
| **전제 조건** | 환자가 **AI 녹음에 동의**한 경우에만 (`visits.ai_recording_consent`) — 미동의 시 UI에서 차단 |
| 입력 | `audio_base64` (webm/opus, 16kHz) |
| 1단계 전사 | **OpenAI Whisper** (`whisper-1`, `language=ko`) |
| 2단계 요약 | `claude-haiku-4-5-20251001`, max_tokens 800 |
| 가드 | 전사 결과 10자 미만이면 400 "녹음 내용이 너무 짧습니다" |
| 저장 | `visit_ai_results.transcript` / `visit_consultations.consultation_summary` |
| **음성 원본** | **저장하지 않음** — 브라우저에서 base64로 전송 후 전사문만 보관 |

**출력 스키마**
```json
{
  "consultation_summary": ["진료 핵심 3-5개"],
  "prescription_plan": ["처방/시술 계획"],
  "follow_up": "다음 방문 계획",
  "updated_soap": { "s": "", "o": "", "a": "", "p": "" },
  "doctor_memo": "의사 메모 요약 2-3문장"
}
```
**제약**: 한국어 / 의학적으로 정확·간결 / **환자 이름·개인정보 제외**

### AI-4. 환자 안내문 초안 ⭐ 사람 검증 필수
`supabase/functions/generate-patient-handout/index.ts`

| 항목 | 값 |
| --- | --- |
| 입력 | 의사 메모(`visit_consultations.memo`) + 음성 요약(`consultation_summary`) |
| 입력 없을 때 | **422 `no_source`** — "진료 메모나 음성 요약이 없어 초안을 만들 수 없습니다" |
| 모델 | `claude-haiku-4-5-20251001`, max_tokens 900 |
| 출력 | 텍스트 (`■ 오늘 받으신 진료` / `■ 처방·복약 안내` / `■ 생활 주의사항` / `■ 다음 방문`) |
| 저장 | **AI 출력은 저장하지 않음.** 의사가 확인·수정해 **확정한 내용만** 저장·인쇄 |

**제약(가장 강함 — 환자에게 직접 나가는 문서)**
- 따뜻한 존댓말, 초등 고학년 수준의 쉬운 말
- 의학 용어는 반드시 풀어서 ("낭종"→"물혹", "경과 관찰"→"지켜보기")
- **입력에 있는 내용만 사용. 진단·약·수치를 절대 지어내지 않는다. 근거 없으면 섹션 생략**
- **음성 요약의 잡음·오인식을 고려해, 불확실하거나 앞뒤가 안 맞는 내용은 넣지 않는다**

> 🛡️ **이 기능의 안전 설계가 시스템 전체의 모범**: AI는 초안까지만, 환자에게 나가는 것은 반드시 사람(의사)이 확정한 것. 코드 주석에도 명시돼 있다.

`supabase/functions/generate-patient-summary/index.ts`

| --- | --- |

## 3. 데이터 흐름과 외부 전송

```
[브라우저]                    [Supabase Edge Function]              [외부 AI]
문진/메모/음성  ──인증(JWT)──▶  인증·역할 검증(2026-08 적용)
                              ├─ 문진 JSON        ──────────────▶  Anthropic  (브리핑/SOAP)
                              ├─ 음성 base64      ──────────────▶  OpenAI     (Whisper 전사)
                              │  └ 전사문         ──────────────▶  Anthropic  (요약)
                              └─ 메모+요약        ──────────────▶  Anthropic  (안내문/발송문)
                                    │
                                    ▼
                              Supabase DB 저장
```

**외부로 나가는 것**: 문진 내용, 진료 메모, 음성 전사문 — **환자 진료정보가 Anthropic/OpenAI API로 전송된다.**
**나가지 않는 것**: 음성 원본 파일(전사 후 폐기), 서비스 롤 키.
**키 보관**: `ANTHROPIC_API_KEY`, `OPENAI_API_KEY`는 Supabase 엣지 함수 환경변수에만 존재 (`.env`·클라이언트 번들에 없음).

> ⚠️ 원칙 D의 메모: *"의료 진료기록 외부 전송이 민감하므로, 오픈모델 로컬 운영은 고급 주제가 아니라 결국 가야 할 길일 수 있음."* — 현재는 전량 외부 API 전송이다. 개인정보 동의서에 AI 처리 고지가 포함돼 있는지 확인 필요.

## 4. 🔴 발견된 결함 — Sonnet 경로 사용 불가 (실측)

**증상**: 원장이 브리핑/SOAP에서 **"🧠 Sonnet"을 선택하면 실패**한다. 화면엔 "서비스 오류가 발생했습니다"만 표시된다.

**실측 결과 (2026-08-10, 배포된 함수 직접 호출)**

| 호출 | 결과 |
| --- | --- |
| Haiku 브리핑 | ✅ 정상 (JSON 반환) |
| Haiku SOAP | ✅ 정상 |
| **Sonnet SOAP** | ❌ `SERVICE_ERROR` |

**원인**: 코드가 `claude-sonnet-4-20250514`를 지정하고 있다. 이 모델은 **deprecated 상태이며 은퇴 일정(2026-06-15)이 지났다.** Haiku(`claude-haiku-4-5-20251001`)는 현행 모델이라 정상 동작한다.

**수정**: `generate-briefing/index.ts:27` 의 모델 ID를 현행 Sonnet으로 교체
```ts
// 변경 전
model === "sonnet" ? "claude-sonnet-4-20250514" : "claude-haiku-4-5-20251001"
// 변경 후
model === "sonnet" ? "claude-sonnet-5" : "claude-haiku-4-5-20251001"
```
수정 후 **엣지 함수 재배포 필요** (`supabase functions deploy generate-briefing --project-ref <project-ref>`).

> 이 결함은 에러 메시지가 전부 `SERVICE_ERROR`로 뭉개져 있어 원인 파악이 어려웠다 — §5의 "에러 규격" 항목과 직결된다.

## 5. ⭐ 설계 원칙(A~H) vs 현재 구현 — 격차표

| 원칙 | 요구 | 현재 상태 | 판정 |
| --- | --- | --- | --- |
| **A. 모델은 부품, 자산은 분리** | 프롬프트·페르소나·평가셋을 모델과 분리 보존 | 프롬프트가 엣지 함수 코드에 하드코딩. 모델 ID도 코드에 직접 | ❌ |
| **B. 계산은 코드, 이해는 LLM** | 집계·점수는 코드/DB | KI 총점은 코드에서 합산, 태그도 코드에서 생성. LLM은 해석만 | ✅ |
| **C. temperature 분리** | 분류·요약 0~0.2 / 안내문 0.7 | **어느 함수에도 `temperature` 미설정** (전부 기본값) | ❌ |
| **D. 의료약어 전처리 사전** | 모델이 틀리는 약어만 등록 | 미적용 — 다만 원칙상 "틀리는 게 확인되면" 하는 것이라 현시점 문제 아님 | ➖ 보류 |
| **E. 프롬프트 6요소** | Role·Context·Task·Format·Constraints·Examples | Role/Task/Format/Constraints는 충실. **Examples(few-shot) 전무** | ⚠️ 부분 |
| **F. 화면=페르소나** | Role만 바꿔 화면별 요약 | 의료진용/환자용 페르소나가 실제로 분리돼 동작 중. 단 `personas.json` 분리는 아님 | ✅ 실질 충족 |
| **G-1. JSON 스키마=계약서** | `response_format`으로 JSON 강제 | **정규식 `/\{[\s\S]*\}/`로 JSON 추출** — 모델이 설명을 덧붙이면 파싱 실패 위험 | ❌ |
| **G-2. 칸 분리로 환각 차단** | 과거력 ≠ 주요진단 | 브리핑에 `history_highlights` / `differential_hints` 분리, SOAP는 S/O/A/P 분리 | ✅ |
| **G-3. 프롬프트 .md 자산화 + 변경 이력** | `prompts/*.md`, 버전 기록 | 미적용 — 프롬프트 수정 이력 추적 불가 | ❌ |
| **H-8. 평가셋 자동 채점** | 진료기록 20~30건 + 정답 요약 | 없음. 모델·프롬프트 교체 시 품질 판단 근거 없음 | ❌ (원칙상 "SaaS 돌기 시작하면") |

**환각 방지 장치는 잘 돼 있다**(원칙 E의 Constraints가 의료의 생명줄): 안내문의 "입력에 있는 내용만 사용, 지어내지 않는다", 음성 요약의 "개인정보 제외", 브리핑의 "null 필드 무시"가 모두 명시돼 있다.

## 6. 안전장치 요약

| 장치 | 구현 |
| --- | --- |
| **사람 검증(Human-in-the-loop)** | 환자 안내문은 의사 확정본만 출력. 진료요약 발송은 승인 단계 필수 |
| **동의 게이트** | AI 녹음은 환자 동의(`ai_recording_consent`) 시에만 가능 |
| **수동 트리거** | AI 생성은 자동이 아닌 버튼 클릭 (비용·오남용 방지) |
| **환각 차단 제약** | 프롬프트에 "입력에 없으면 생략", "지어내지 않는다" 명시 |
| **개인정보 최소화** | 음성 요약 프롬프트에 "환자 이름·개인정보 제외" |
| **음성 원본 미보관** | 전사 후 텍스트만 저장 |
| **인증** | 5개 함수 전부 의료진 JWT + 역할 검증 (2026-08-10 적용) |
| **오류 격리** | 브리핑 실패 시 에러 바운더리로 화면 보호, 크레딧 부족은 별도 메시지 |
